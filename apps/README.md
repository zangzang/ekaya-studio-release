# 앱별 샘플 파일

DevVault 앱들이 다루는 **프로젝트 파일 샘플**입니다. 설치 후 바로 열어보면서
기능을 확인해 볼 수 있도록 실제 동작하는 파일을 그대로 올려둡니다.

| 앱 | 확장자 | 샘플 | 들어 있는 제품 |
|---|---|---|---|
| [WBS](wbs/) | `.wbs.json` | 2개 | DevVault |
| [Data Modeler](data-modeler/) | `.dmodel.json`, `.sql` | 7개 | DevVault, DevVault Modeler |

## 내려받는 법

- **파일 하나** — 위 링크에서 파일을 연 뒤 우측 상단 **Download raw file** 버튼
- **전부 한 번에** — 레포 첫 화면의 **Code ▾ → Download ZIP**

내려받은 파일은 앱의 **열기**(`Ctrl+O`)로 선택하거나 창에 끌어다 놓으면 열립니다.

## 주의

샘플은 기능 시연용 **가상 데이터**입니다. 실제 프로젝트·조직 데이터가 아닙니다.
샘플을 열어 편집해도 원본 파일은 저장하기 전까지 바뀌지 않지만, 습관적으로
사본을 만들어 쓰는 편이 안전합니다.
